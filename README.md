# 🚀 Automated Tech News → LinkedIn Content Engine

An end-to-end automation that curates the latest tech news, filters out noise, generates AI-written LinkedIn posts, automatically publishes them to a LinkedIn Company Page, and sends email copies for monitoring.

This project focuses on **automation system design**, not just tool usage.

---

## 📌 Project Overview

This automation runs daily and performs the following tasks:
- Fetches the latest AI & Big Tech news
- Filters only relevant and high-signal stories
- Uses AI to generate a LinkedIn-ready post
- Auto-publishes the post to a LinkedIn Company Page
- Emails a copy of the post for visibility and backup

The project was built to understand **real-world automation architecture**, including triggers, filters, routing, and safe API usage.

---

## ❓ Problem It Solves

Manually creating tech content involves:
- Checking multiple news sources daily
- Deciding what’s worth sharing
- Writing consistent LinkedIn posts
- Posting and monitoring engagement

This automation solves:
- ❌ Information overload  
- ❌ Inconsistent posting habits  
- ❌ Manual content creation effort  
- ❌ Missed opportunities to build an audience  

---

## 🛠️ Tools Used

### Automation Platform
- **Make.com** – Workflow orchestration, scheduling, routing
### AI
- **OpenAI** – Generates LinkedIn-ready content from news input
### Data Source
- **RSS (Google News)** – Tech, AI, and Big Tech updates
### Distribution & Monitoring
- **LinkedIn Company Page** – Official API auto-posting
- **Gmail** – Email copy for monitoring and record-keeping

---

## 🔄 Workflow Explanation

### High-Level Flow
- Scheduler (Daily at 10:00 AM) 
- RSS Feed (Latest Tech News)
- Filter (Relevant AI / Big Tech news only)
- AI (Generate LinkedIn post)
- Router
- ├── LinkedIn Page (Auto-post)
- └── Gmail (Email copy)

---

### Key Design Decisions

- **RSS as the trigger** instead of webhooks (pull vs push)
- **Filter before AI** to reduce noise and unnecessary token usage
- **Router** to send one AI output to multiple destinations
- **Company Page posting** to stay API-safe and avoid account risk
